# RightBTRadio 0.1.0-alpha

Primera versión publicable.

## Qué hace

Windows no maneja dos radios Bluetooth a la vez. Con un adaptador USB conectado
teniendo uno integrado, uno de los dos queda con el código de problema 31 y deja de
servir; resolverlo a mano es entrar al Administrador de dispositivos cada vez que se
conecta o se desconecta el adaptador.

RightBTRadio lo hace solo. Se le indica el orden de preferencia entre los radios y, al
conectar o desconectar uno, deja habilitado el presente de mayor prioridad, deshabilita
el resto y reinicia el nodo del ganador para que Windows cargue su controlador.

## Requisitos

Windows 11 x64. El instalador pide elevación una vez, porque habilitar y deshabilitar
nodos PnP la exige.

Si faltan el .NET Desktop Runtime o el Windows App Runtime, el instalador los descarga
de Microsoft. En una máquina que ya los tiene no descarga nada.

## Instalación

Ejecute `RightBTRadio-0.1.0-alpha-Setup.exe`. Verifique la descarga contra el archivo
`.sha256` que la acompaña.

Al terminar, abra la ventana de ajustes desde el área de notificación, agregue sus
radios al grupo y ordénelos: el primero de la lista es el que queda habilitado.

Mientras el grupo esté vacío la aplicación no toca nada.

## Alpha significa

La lógica está probada de punta a punta sobre hardware real —conectando y
desconectando el adaptador, cerrando e iniciando sesión, instalando, desinstalando y
reinstalando— pero sobre **una sola estación**, con un radio interno Qualcomm Atheros
AR3012 y un adaptador USB Toocki. Otro hardware puede comportarse distinto.

Antes de probarlo conviene saber que deshabilitar un radio corta todo lo emparejado a
él. Si el radio que pierde la prioridad es el que lleva su teclado o su ratón, se queda
sin ellos hasta reconectarlos por cable. El menú del área de notificación tiene
**Habilitar todos los radios** para salir de eso, y la desinstalación también los
devuelve.

## Limitaciones conocidas

- Las tareas programadas que hacen el trabajo elevado son por usuario. Un segundo
  usuario de la misma máquina las registra desde la ventana de ajustes.
- Windows retrasa las entradas de la clave `Run` un par de minutos tras iniciar sesión.
  En ese intervalo la aplicación todavía no resuelve; como el estado anterior persiste,
  solo importa si se conecta un radio justo entonces.
- El modelo admite varios grupos de prioridad, pero la ventana solo expone uno.
- Queda por comprobar si reiniciar el nodo es la única forma de recuperar un radio con
  el problema 31.
