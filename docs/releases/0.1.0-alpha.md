# RightBTRadio 0.1.0-alpha

Primera versión publicada.

![Ventana de ajustes de RightBTRadio](https://raw.githubusercontent.com/n-a-monterocarvajal/RightBTRadio/main/docs/images/ajustes.png)

## Qué hace

Windows no puede usar dos radios Bluetooth a la vez. Si conecta un adaptador USB a un
equipo con Bluetooth integrado, uno de los dos queda con el código de problema 31 y
deja de funcionar. Sin esta aplicación, hay que entrar al Administrador de
dispositivos cada vez que se conecta o se desconecta el adaptador.

RightBTRadio lo resuelve de forma automática. Usted indica el orden de preferencia de
sus radios. Cuando se conecta o se desconecta uno, la aplicación deja habilitado el
primer radio conectado de la lista y deshabilita los demás. Si el radio habilitado
quedó con el código 31, reinicia su nodo para que Windows cargue el controlador.

## Requisitos

Windows 10 versión 1809 o posterior, de 64 bits. Solo se probó en Windows 11.

El instalador pide permiso de administrador una vez, porque Windows lo exige para
habilitar y deshabilitar dispositivos. Si faltan el .NET Desktop Runtime o el Windows
App Runtime, los descarga de Microsoft. Si ya están instalados, no descarga nada.

## Instalación

1. Descargue `RightBTRadio-0.1.0-alpha-Setup.exe` y compruebe su SHA-256 con el
   archivo `.sha256` que lo acompaña.
2. Ejecute el instalador.
3. Abra los ajustes con doble clic en el icono de RightBTRadio del área de
   notificación.
4. Agregue sus radios al grupo y ordénelos con Subir y Bajar. Queda habilitado el
   primer radio conectado de la lista.

Mientras el grupo esté vacío, la aplicación no modifica ningún radio.

## Antes de probarla

Esta es una versión alpha. Se probó con hardware real: conectando y desconectando el
adaptador, cerrando e iniciando sesión, y al instalar, desinstalar y volver a
instalar. Pero se probó en **un solo equipo**, con un radio interno Qualcomm Atheros
AR3012 y un adaptador USB Toocki. Otro hardware puede comportarse distinto.

Al deshabilitar un radio se desconecta todo lo que está emparejado con él. Si su
teclado o su mouse usan el radio que queda deshabilitado, dejarán de responder hasta
que los conecte por cable. Para recuperarlos, haga clic con el botón derecho en el
icono del área de notificación y elija **Habilitar todos los radios**. Desinstalar la
aplicación también habilita todos los radios.

## Limitaciones conocidas

- Las tareas programadas que hacen el trabajo con privilegios son por usuario. Otro
  usuario del mismo equipo las registra al abrir la aplicación.
- Windows retrasa un par de minutos las aplicaciones de inicio después de iniciar
  sesión. Durante ese tiempo la aplicación no aplica la prioridad. El estado anterior
  se mantiene, así que solo importa si se conecta un radio en ese intervalo.
- Falta comprobar si reiniciar el nodo es la única forma de recuperar un radio con el
  código 31. El seguimiento está en los
  [issues](https://github.com/n-a-monterocarvajal/RightBTRadio/issues).
